## ✨ Features

- **Modern Design:** Sleek aesthetic suited for fine dining, cafes, or modern food businesses.
- **Fully Responsive:** Mobile-first design that adapts seamlessly to phones, tablets, and desktops.

- **SEO Optimized:** Clean semantic HTML5 structure.

## 🛠️ Tech Stack

- **HTML5** for structure
- **Tailwind CSS** for styling
- **Vanilla JavaScript** for interactive elements (mobile menu, navigation, etc.)

## 🚀 Quick Start (Local Setup)

To run and edit this project on your local machine, follow these steps:

### Prerequisites
- [Git](https://git-scm.com/) installed on your machine.
- We recommend using the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code.

### Installation

**1. Clone the repository:**
```bash
git clone https://github.com/webdrakib/segreto-rest.git
```

**2. Navigate to the project directory:**

```Bash
cd segreto-rest
```
**3. Run the local development server:**
Open index.html using the VS Code Live Server extension. If you are using the Tailwind CLI for custom compilation, install dependencies and run your build script:

```Bash
npm install
npm run dev
```

### 🎨 How to Customize

- This template is designed to be easily modified for any brand:

- Colors & Branding: Open tailwind.config.js to modify the primary and secondary brand colors.

- Content: All text, menus, and pricing are located directly inside index.html.

- Images: Replace the placeholder images in the asset folder with your own photography, or update the src paths in the HTML.
