# 🍽️ Segreto Restaurant Website

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/webdrakib/segreto-rest)

A modern, fully responsive restaurant website template featuring a premium UI, a dedicated menu section, and a high-conversion layout designed for local food businesses.

**[View Live Demo](https://segreto-rest.vercel.app/)** | **[Visit My YouTube Channel](https://www.youtube.com/channel/UCtZ2DhgOG3Gx0BQiiNmwDIg)**

---

## ✨ Features

* **Modern Design:** Sleek aesthetic suited for fine dining, cafes, or modern food businesses.
* **Fully Responsive:** Mobile-first design that adapts seamlessly to phones, tablets, and desktops.
* **Tailwind CSS Powered:** Highly customizable utility classes for rapid styling adjustments.
* **SEO Optimized:** Clean semantic HTML5 structure.

## 🛠️ Tech Stack

* **HTML5** for structure
* **Tailwind CSS** for styling
* **Vanilla JavaScript** for interactive elements (mobile menu, navigation, etc.)
